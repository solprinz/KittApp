## ✨ Características Principales

* **Catálogo de Felinos en Adopción:** Fichas individuales con foto, nombre, edad, sexo, ubicación y fecha de publicación.
* **Formulario para Publicar Adopción:** Módulo con validación de campos obligatorios para registrar gatos que buscan hogar (datos de salud, vacunas, esterilización y descripción).
* **Validaciones con Modales Interactivos:** Uso de SweetAlert para confirmaciones y alertas de validación de formularios en tiempo real.
* **Sección de Contacto & Newsletter:** Formularios integrados para consultas de ayuda y suscripción a novedades.
* **Diseño 100% Responsive:** Estructura adaptativa mediante SASS y Bootstrap para una visualización fluida en cualquier pantalla.
